# First Priority — FISH Mini App

Telegram Mini App (TWA) для First Priority: главная о служении, разбор цикла
FISH по неделям, вкладка «Команда» с исходными файлами, и «Мои 5» — цифровая
карточка молитвы. RU / EN / RO / UK.

## Структура проекта

```
index.html          — разметка приложения (splash, шапка, 4 вкладки, sheet)
css/style.css        — вся стилистика: цвета, типографика, карточки, анимации
js/telegram-init.js  — подключение Telegram WebApp SDK, тема, хаптики, CloudStorage
js/icons.js           — все SVG-иконки (fish, недели, навигация, UI)
js/i18n.js             — весь текстовый контент на 4 языках
js/app.js               — рендер экранов, навигация, "Мои 5", открытие карточек недели
assets/img/              — фото и логотип (взяты из ваших исходников)
docs/                       — оба ваших PDF (мануал + слайды) — доступны для скачивания в приложении
```

## Как посмотреть локально

Любой статический сервер подойдёт, например:

```
cd first-priority-app
python3 -m http.server 8080
```

и открыть `http://localhost:8080` в браузере (Telegram-специфичные функции —
тема, хаптики, CloudStorage — включатся автоматически внутри Telegram,
а в обычном браузере просто работают в "dev"-режиме с базовыми настройками).

## Как подключить как Telegram Mini App

1. Разместите папку на любом HTTPS-хостинге (GitHub Pages, Netlify, Vercel,
   Cloudflare Pages — подойдёт любой, приложение полностью статическое).
2. В @BotFather: `/newapp` (или `/myapps` → выбрать бота → Edit Mini App)
   и указать URL, где лежит `index.html`.
3. Проверьте, что `docs/*.pdf` тоже доступны по HTTPS (для кнопок
   «Открыть»/«Скачать» на вкладке Команда).

## Что можно донастроить

- **Памятка по свидетельству** (вкладка FISH → Share → «Как подготовить
  своё свидетельство») — сейчас взята из мануала (стр. 22) и флаера «ВАША
  ВЕРА» из слайдов. Если пришлёте отдельный файл — заменю текст в
  `js/i18n.js` → `testimony` (по всем 4 языкам) на ваш вариант.
- **4 языка**: весь текст лежит в `js/i18n.js`, разделён по ключам `ru / en / ro / uk` —
  правки текста делаются точечно, без переписывания вёрстки.
- **Цвета недель** заданы в `css/style.css` в `:root` (`--focus`, `--inspire`,
  `--share`, `--hook`) — взяты из вашей презентации.
